# Mon Trajet en Arabe

App iOS (Capacitor) 100 % audio pour apprendre l'arabe littéraire (arabe standard moderne). Dupliquée depuis le japonais.

- Nom App Store : `Apprendre Arabe : Mon Trajet`
- Bundle ID : `com.tonstudio.montrajet.arabe`
- RevenueCat : projet `Mon Trajet Arabe`, produit `version_complete_ar`, entitlement `mon_trajet_arabe_pro`
- Codemagic : profil `mon_trajet_arabe_app_store`
- TTS `ar-SA`. Phrases `{fr, ar (vocalisé), ro (translittération), lit? (niveau 1)}`. 70 points de grammaire.
